# Dataset Information

This project uses images of Philippine coins for the coin image-processing
laboratory activity. The images were provided by the instructors.

The coin images are not included in the public repository because their
original sources and redistribution permissions are unknown. They should only
be used in the authorized course environment or obtained again through an
authorized source.

The selected images represent coins whose total value is ₱21.10:

- One ₱20.00 coin
- Two ₱0.50 coins
- One ₱0.10 coin

The images are used for image-processing experiments involving:

- Grayscale conversion
- Median filtering
- Gaussian smoothing
- Convolution
- Image sharpening
- Edge detection

Expected image files are documented in the notebook. The notebook requires the
instructor-provided coin files in its local `COINS/` data directory when it is
run.
